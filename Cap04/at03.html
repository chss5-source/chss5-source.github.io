Seção 2 — Ranking de Tecnologias

  1. HTML

    É a linguagem responsável pela estrutura das páginas web.

  2. CSS

    Define o estilo e a aparência das páginas.

  3. JavaScript

    Adiciona interatividade e dinamismo aos sites.

  4. Node.js

    Permite utilizar JavaScript no desenvolvimento backend.

  5. React

    Framework muito utilizado para criar interfaces modernas.

Seção 3 — Glossário de Termos Técnicos

HTML
Linguagem de marcação utilizada para estruturar páginas web.
CSS
Linguagem responsável pela estilização das páginas.
JavaScript
Linguagem de programação para tornar páginas interativas.
Pode ser utilizada tanto no frontend quanto no backend.
DOM
Modelo de objetos que representa os elementos da página.
API
Interface utilizada para comunicação entre sistemas.
Pode fornecer dados ou funcionalidades.
HTTP
Hypertext Transfer Protocol
Protocolo utilizado para comunicação entre navegador e servidor.
URL
Endereço Web
Localização de um recurso na internet.
DNS
Sistema que converte nomes de domínio em endereços IP.
